# Schema copy

`labconstrictor-app.schema.json` is a copy of the schema of the LabConstrictor App Centre manifest
(`labconstrictor-app.yaml`). The authority is the LabConstrictor site repository
(`schema/labconstrictor-app.schema.json`, published at
https://labconstrictor.cellmig.org/schema/labconstrictor-app.schema.json). When that file changes, copy it here,
into `.template_sync/resources/` for the next template version, and into the repository initialiser
(`LabConstrictor_streamlit/schemas/`).
